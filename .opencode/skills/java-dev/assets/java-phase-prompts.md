# Java Phase Prompt Examples

## Implement one phase

```text
Use the assessment-java-implementer skill.
Implement Phase N only.
Follow .aicontext/deliverables/task-backlog.md and .aicontext/phases/NN-*.md.
Run mvn clean test and update completed task checkboxes only after success.
```

## Implement one task

```text
Use the assessment-java-implementer skill.
Implement task N.M from Phase N only.
Do not implement future tasks.
Run mvn clean test and update task tracking after success.
```

## Review before coding

```text
Use the assessment-java-implementer skill in review-before-code mode.
Analyze Phase N, list intended files and tests, and wait for approval before editing.
```

## Fix failing tests

```text
Use the assessment-java-implementer skill.
Fix the failing tests introduced in Phase N only.
Do not refactor unrelated code.
Run mvn clean test.
```
