# Phase Implementation Checklist

Use this checklist for every implementation phase.

## Before coding

- [ ] Read `AI_CONTEXT.md`.
- [ ] Read `.aicontext/manifest.yaml`.
- [ ] Read project decisions.
- [ ] Read the selected phase plan.
- [ ] Read the task backlog.
- [ ] Identify in-scope tasks.
- [ ] Identify out-of-scope tasks.
- [ ] Inspect existing code.
- [ ] Inspect `pom.xml`.
- [ ] State implementation intent.

## During implementation

- [ ] Modify only necessary files.
- [ ] Keep architecture boundaries.
- [ ] Add meaningful tests.
- [ ] Avoid future phases.
- [ ] Avoid optional scope unless selected.
- [ ] Avoid unapproved dependencies.

## Validation

- [ ] Run the phase validation command.
- [ ] Fix selected-phase failures.
- [ ] Do not remove tests to pass.
- [ ] Report results.

## Tracking

- [ ] Mark completed tasks after success.
- [ ] Add implementation note if useful.
- [ ] Ask before changing project decisions.
- [ ] Stop after the selected phase/task.
